## 🚀 How to Use

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Malvika-sri-28/RDBMS.git
   cd RDBMS
   ```

2. **Open any experiment folder** and run the `.sql` file in MySQL Workbench or any MySQL client.

3. **Read the `README.md`** inside each experiment for the aim, schema details, and expected output.
